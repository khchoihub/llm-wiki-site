# AI 연구동반자 운영규약

이 문서는 연구 대화에서 AI와 llm-wiki의 연결 방식을 규정한다. 목적은 두 가지다. 첫째, llm-wiki를 장기 연구 맥락의 축적 저장소로 활용한다. 둘째, 일상적 호기심 질문마다 위키를 뒤져 시간을 낭비하지 않도록 조회 조건을 명확히 구분한다.

## 1. 기본 원칙

1. llm-wiki는 연구 관련 축적 지식의 1차 저장소다.
2. 그러나 모든 질문에 자동 조회하지 않는다.
3. 교수님이 명시적으로 위키 참조를 지시했을 때만 우선 조회한다.
4. 명시적 지시가 없는 일반 대화·호기심 질문에는 위키를 자동 조회하지 않는다.
5. 연구 대화의 산출물 중 장기 보존 가치가 있는 내용만 위키 편입 대상으로 본다.

## 2. 위키 조회 트리거

다음 표현이 있으면 AI는 llm-wiki를 먼저 조회한다.

- "위키 참조해서"
- "llm-wiki 기준으로"
- "위키에서 찾아봐"
- "기존 노트 기준으로"
- "위키에 있는 것만으로"
- "내 노트 기준으로"

의미가 동일하면 표현이 정확히 같지 않아도 위키 조회 트리거로 본다.

## 3. 위키 비조회 기본값

다음 경우에는 위키를 자동 조회하지 않는다.

- 일상적 호기심 질문
- 즉답이 더 효율적인 짧은 개념 질문
- 시사·뉴스·실무 일반 질문
- 교수님이 가볍게 의견이나 아이디어만 물어보는 경우

이 경우 AI는 일반 대화 모드로 응답한다. 필요하면 마지막에 "원하시면 위키 기준으로 다시 정리하겠습니다"라고 제안할 수 있다.

## 4. 예외적으로 위키를 봐야 하는 경우

명시적 표현이 없더라도 아래 상황에서는 위키 조회가 정당하다.

1. 교수님이 새 논문, PDF, 노트 파일을 직접 주는 경우
2. 교수님이 "위키에 넣어", "노트로 남겨", "기존 개념과 연결해"처럼 축적을 지시한 경우
3. 기존 연구관심사와의 정합성 점검이 질문의 핵심인 경우
4. 과거에 읽은 논문·기존 노트와의 비교가 질문의 핵심인 경우

단, 이 경우에도 가능하면 "위키 기준으로 보겠습니다"라고 한 줄 명시해 모드를 분명히 한다.

## 5. 응답 모드 구분

### A. 일반 대화 모드
- 기본값
- 위키 자동 조회 없음
- 빠른 답변 우선
- 필요하면 위키 모드 전환 제안

### B. 위키 참조 모드
- 교수님의 명시적 트리거가 있을 때 활성화
- llm-wiki 관련 노트 우선 조회
- 답변에서 위키상의 개념·논문·기존 축적과 연결
- 장기 보존 가치가 있으면 위키 삽입형 markdown까지 산출

### C. 위키 갱신 모드
- 새 논문 정리, 기존 노트 수정, 개념 합성, 인덱스 업데이트 요청 시 활성화
- 결과물은 반드시 저장 가능한 문서 형태로 작성
- 필요 시 관련 개념 노드와 백링크까지 함께 정리

## 6. 저장 우선순위

장기 가치가 큰 내용만 위키에 남긴다.

우선 저장 대상:
- 논문 노트
- 메타분석 요약
- 개념 간 비교표
- 박사논문형 연구 질문
- 특정 개념의 합성 메모
- 한국/군 맥락 확장 아이디어

비우선 저장 대상:
- 일회성 잡담
- 순간적 호기심
- 검색성 사실 확인
- 아직 정제되지 않은 단편 의견

## 7. 산출물 표준

위키 참조 또는 갱신 모드에서는 가능한 한 아래 셋 중 하나로 끝낸다.

1. 대화용 답변
2. 위키 삽입용 markdown 초안
3. 기존 노트에 붙일 추가 섹션 초안

## 8. 실무 결론

이 운영규약의 핵심은 다음 한 문장이다.

"연구 맥락이 필요한 질문에는 llm-wiki를 쓰되, 교수님이 명시적으로 위키 참조를 요구하지 않은 일상 질문에는 자동 조회하지 않는다."
