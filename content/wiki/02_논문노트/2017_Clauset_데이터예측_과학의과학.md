# 과학의 과학에서 데이터 기반 예측 (Data-Driven Predictions in the Science of Science)

## 메타데이터
- 저자: Aaron Clauset, Daniel B. Larremore, Roberta Sinatra
- 연도: 2017
- 저널: Science, Vol. 355, No. 6324, pp. 477-480
- DOI: 10.1126/science.aal4217
- 연구 유형: 리뷰 (에세이)

## 연구 질문 및 가설
"과학의 과학(science of science)"—과학적 발견 과정 자체를 과학적으로 연구하는 분야—이 제공하는 데이터 기반 예측의 가능성과 한계는 무엇인가?

## 이론적 틀
- 핵심 개념: 과학사회학, 데이터 예측, 계량서지학(bibliometrics)
- 독립변수(IV): 연구자·기관·논문의 네트워크 구조, 인용 패턴
- 종속변수(DV): 연구 영향력, 혁신적 발견 예측 가능성
- 이론적 근거: 복잡계 과학, 네트워크 분석, 기계학습

## 방법론
- 데이터: 수백만 건의 논문, 인용, 연구자 경력 데이터
- 분석 방법: 빅데이터 분석 + 예측 모형 (기계학습)
- 특이사항: 과학 발견의 예측 가능성에 관한 학제적 탐색 에세이

## 핵심 발견
- 과학 발견의 일부 패턴은 데이터로 예측 가능: 논문 영향력, 협력 네트워크 위치, 경력 발전 궤적
- **예측 가능한 것**: 인용 궤적, 연구자 경력 정점 시기, 협력 네트워크 발전
- **예측 어려운 것**: 개별 혁신적 아이디어의 등장, 패러다임 전환
- 데이터 기반 예측은 현재 자원 배분(연구비, 채용)에 이미 활용되고 있음
- **위험**: 예측이 자기실현적 예언(self-fulfilling prophecy)이 될 수 있어 다양성 저해 가능

## 이론적 기여
정책 연구에서 데이터 기반 예측의 가능성과 윤리적 한계를 동시에 제기. 근거기반 의사결정([[증거기반정책]])에서 예측 모형 활용의 조건을 이론화하는 기반.

## 향후 연구 방향
### AI 추론 [AI 제안]
- 공공정책 분야에서 데이터 기반 자원 배분의 예측 편향 연구
- 한국 연구개발 정책에서 데이터 예측 모형 도입 효과 분석

## 재현·발전 가능성 [AI 분석]

- 방법론: 네트워크 분석, 기계학습 예측 모형
