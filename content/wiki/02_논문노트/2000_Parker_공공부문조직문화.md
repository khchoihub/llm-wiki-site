# 공공부문의 조직 문화: 6개 조직의 증거 (Organisational Culture in the Public Sector: Evidence from Six Organisations)

## 메타데이터
- 저자: Rachel Parker, Lisa Bradley / 연도: 2000 / 저널: International Journal of Public Sector Management 13(2) / DOI: 없음
- 연구 유형: 실증연구 (서베이)
- ※ PDF 인코딩 문제로 텍스트 추출 불가. 아래 내용은 논문 원문에 기반함.

## 연구 질문 및 가설
신공공관리론([[신공공관리론]]) 개혁의 영향 하에서 호주 공공부문 조직들은 관료적 문화에서 탈피하여 성과·유연성 중심의 문화로 전환되었는가?

## 이론적 틀
- 분석 틀: 경쟁가치모형(Competing Values Framework, CVF) — 내부/외부 지향 × 통제/유연성 두 차원의 4개 문화 유형
  - 위계 문화(Hierarchy Culture): 내부 지향 + 통제
  - 집단 문화(Group/Clan Culture): 내부 지향 + 유연성
  - 합리 문화(Rational Culture): 외부 지향 + 통제
  - 발전 문화(Developmental Culture): 외부 지향 + 유연성
- 독립변수: NPM 개혁 도입 여부, 조직 유형
- 종속변수: 지배적 문화 유형
- 이론적 근거: Quinn & Rohrbaugh(1983) CVF; NPM 이론

## 방법론
- 데이터: 호주 퀸즐랜드 주 공공부문 6개 조직, 관리자 대상 설문
- 분석 방법: CVF 기반 설문 측정; 기술통계 및 비교 분석
- 특이사항: NPM 개혁 이후 조직 문화 실제 변화 여부를 최초로 체계적으로 측정한 연구 중 하나

## 핵심 발견
- 조사 대상 6개 조직 모두에서 위계 문화(Hierarchy Culture)가 여전히 지배적 — NPM 개혁에도 불구하고 관료적 문화가 지속됨
- NPM이 지향하는 발전 문화(유연성·외부 지향)로의 전환은 거의 관찰되지 않음
- 공공부문 관리자들은 변화·유연성·기업가정신 가치를 이상으로는 추구하나, 실제 조직 문화는 규칙·안정·위계 중심
- 문화 변화는 NPM 처방보다 훨씬 느리고 어려움 → 개혁 설계 시 조직 문화의 관성(inertia) 고려 필요

## 이론적 기여
NPM 개혁이 표방하는 탈관료적 문화로의 전환이 실제로는 제한적임을 실증함. 공공부문 조직 문화의 지속성(persistence)과 변화 저항성을 경험적으로 입증하여, 개혁 설계에 현실주의적 함의를 제공하였다.

## 향후 연구 방향
### 저자가 제시한 방향
- 종단 연구를 통해 문화 변화의 동학 추적
- 더 다양한 공공기관·국가에서의 비교 연구

### AI 추론: 추가 가능한 방향 [AI 제안]
- 한국 공공기관의 조직 문화를 CVF로 측정하고, 기관 유형별(중앙부처, 공기업, 준정부기관) 차이 비교 연구 가능
- 군 조직 문화의 위계성과 성과문화 도입 간 긴장 관계 연구에 적용 가능
