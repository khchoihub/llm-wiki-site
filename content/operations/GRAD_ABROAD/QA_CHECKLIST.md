# GRAD/ABROAD 문서 변환 QA 체크리스트

## 실행 체크리스트

- [ ] 프로젝트·경로·문서ID·DB 분류를 확정했다.
- [ ] 변환 전 파일명·frontmatter·내부링크를 기록했다.
- [ ] 기존 노트 전체를 읽었다.
- [ ] 기존 ID를 DB에서 재검증했다.
- [ ] 기존 노트 밖에서도 고정보 스레드 후보를 다시 탐색했다.
- [ ] 다중경로 후보 발굴기를 실행하고 검색 경로별 후보를 기록했다.
- [ ] 주제별 포화 중단 조건을 충족하거나 전량 검토했다.
- [ ] `원본건수`와 DB 조건부 건수를 비교했다.
- [ ] 핵심 명제를 경험담·반복경험·통념·논쟁·편집자종합으로 구분했다.
- [ ] 저장소 밖에 근거 장부를 작성했다.
- [ ] 근거를 A급 앵커·B급 보조·C급 제외로 판정했다.
- [ ] 각 A급 앵커에서 보존할 절차·수치·행동·결과·반론을 기록했다.
- [ ] A급 앵커를 원자적 정보단위로 분해하고 중요도를 매겼다.
- [ ] 각 대절의 편집 논제·메커니즘·반론·근거를 주장 그래프로 만들었다.
- [ ] 필요한 댓글을 확인했다.
- [ ] 고아 댓글과 중복 게시물을 제외했다.
- [ ] 시기·입장·예외가 균형 잡힌 근거를 골랐다.
- [ ] 독자 질문 중심의 새 목차를 먼저 확정했다.

- [ ] 소재의 분포가 아니라 실제 작동 원리와 이해관계를 설명했다.
- [ ] 각 대절에 독자가 새로 배울 구체 정보가 있다.
- [ ] 은어를 최초 1회 설명했다.
- [ ] 수치·연도·사건·변화에 각주를 붙였다.
- [ ] 각주를 단순 출처 표식이 아니라 세부 절차·비유·트리비아·작은 반례·출처 한계를 담는 보조 서술층으로 작성했다.
- [ ] 각주를 가려도 본문의 핵심 논지가 완결되며, 각주를 읽으면 본문에 없는 정보가 추가된다.
- [ ] 대절의 결론·핵심 구분·반론 뒤의 판단만 굵게 표시했다.
- [ ] 굵은 부분만 이어 읽는 스캔 감사와 각주만 읽는 주석 감사를 완료했다.
- [ ] 문단 끝에 서로 다른 기능의 각주가 더미처럼 몰려 있지 않다.
- [ ] 반대 근거와 예외를 표시했다.
- [ ] 초안 이후 핵심 논제별 적대적 반론 검색을 별도로 수행했다.
- [ ] 개인정보와 `source_url`을 제거했다.
- [ ] 파일명·경로·문서ID·원본건수·password를 보존했다.

## 자동 검사 실행

```powershell
python tools/validate_grad_abroad_note.py --note "대상 문서 절대경로" --db "대응 DB 절대경로" --project GRAD
```

`--project`에는 `GRAD` 또는 `ABROAD`를 쓴다. 자동 검사는 후보 오류를 찾는 도구이며 근거의 의미 적합성을 대신하지 않는다.

`possible low-information corpus-summary phrasing` 경고는 자동 오류가 아니지만 수동 완료 차단 항목이다. 해당 문장이 실제 메커니즘·조건·결과를 포함하도록 고쳐지거나, 주변 문맥상 정보 손실이 없다는 검수 기록이 있어야 완료 처리할 수 있다. `no machine-readable DB citations found`가 남은 문서도 완료 처리하지 않는다.

## 수동 스팟체크

1. 각 대절의 핵심 근거를 최소 1개씩 원문과 대조한다.
2. 시계열 절은 이전·이후 근거를 각각 대조한다.
3. 논쟁 절은 지지·반론·예외를 각각 대조한다.
4. 원문에 없는 인과관계·평가·사건이 추가되지 않았는지 통독한다.
5. 기존 문서를 읽지 않은 내부 독자가 이해할 수 있는지 확인한다.
6. 각 대절을 한 문장으로 요약했을 때 `무엇이 많이 언급된다`가 아니라 `무엇이 어떻게 작동한다`가 되는지 확인한다.
7. A급 스레드를 다시 읽고 절차·숫자·행위자·선택·결과·반론 중 유용한 디테일이 소거되지 않았는지 확인한다.
8. 저정보 게시물 여러 개가 고정보 게시물 한 개보다 더 큰 비중을 차지하지 않는지 확인한다.
9. 각주를 가리고 본문만 읽어 논지가 완결되는지 확인한다.
10. 각주만 따로 훑어 본문에 없는 세부·비유·예외·후일담이 실제로 존재하는지 확인한다.
11. 굵은 부분만 이어 읽고 논지의 골격이 보이는지, 감정이나 기관명만 부각되지 않는지 확인한다.
12. 각주 호출이 문단 끝이 아니라 실제로 뒷받침하는 절·문장 바로 뒤에 있는지 확인한다.
