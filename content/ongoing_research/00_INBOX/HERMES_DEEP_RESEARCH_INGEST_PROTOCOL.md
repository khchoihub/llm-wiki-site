# Hermes Deep Research 후처리 프로토콜

이 문서는 외부 Deep Research 결과를 Hermes가 받아 **파일 기반 연구자산**으로 바꾸는 표준 절차입니다.

핵심 원칙은 다음 한 줄입니다.

> 외부 Deep Research는 정찰대, Hermes는 참모본부다.

즉, 외부 결과를 그대로 신뢰하고 끝내지 말고, **저장 → 구조화 → 중복제거 → 관련성 판정 → full text 확보계획 → 다음 작업 큐화**까지 이어가야 합니다.

---

## Hermes에게 붙일 표준 지시문

아래 블록을 외부 Deep Research 결과와 함께 Hermes에 넣습니다.

```text
아래 외부 Deep Research 결과를 교수님 연구 파이프라인 기준으로 후처리하라.

반드시 다음을 수행하라.
1. 출처 링크, DOI, CN, article-id, 제목, 저자, 연도를 최대한 보존하라.
2. 중복 문헌과 사실상 같은 자료를 합쳐라.
3. 국내문헌과 해외문헌, 논문과 정책자료를 구분하라.
4. 각 후보를 A/B/C/D 또는 S/A/B/C로 분류하라.
5. 방법론상 또는 논지상 핵심문헌은 FULLTEXT_NEEDED로 표시하라.
6. 아래 파일 세트로 ongoing_research에 저장하라.
7. 최종 채팅 보고에는 새로 만든 파일 경로와 교수님 승인 필요 항목만 짧게 보고하라.

산출물 파일 세트:
- 01_SEARCH_LOG/{날짜}_{주제}_외부DR검색로그.md
- 02_CANDIDATES/{날짜}_{주제}_외부DR후보표.md
- 03_ABSTRACTS/{날짜}_{주제}_외부DR초록정리.md
- 04_PDFS/{날짜}_{주제}_외부DR_PDF확보현황.md
- 05_READING_QUEUE/읽기대기열.md (필요시 갱신)
- 06_DRAFTS/{프로젝트폴더}/01_문헌지도.md (필요시 갱신)
- 07_AGENT_RUNS/{날짜}_Hermes_{주제}_외부DR_후처리_run.md

후보표에는 반드시 아래 열을 넣어라.
- 번호
- 등급
- 자료유형
- 제목
- 저자/기관
- 연도
- 핵심 주장 요약
- 관련성 판단 이유
- full text 필요 여부
- 확보 상태
- 출처/식별자
- 비고

원칙:
- 외부 모델의 서술을 그대로 복사하지 말고, 연구 파이프라인 형식으로 재구성하라.
- 허위 출처가 의심되면 [검증 필요]로 표시하라.
- 초록만 본 문헌과 원문 확인 문헌을 절대 혼동하지 마라.
- "찾았다"와 "읽을 수 있다"를 구분하라.
```

## 후처리 체크리스트

### 1. 입력물 확인
- 외부 결과에 출처 링크가 실제로 있는가
- 표가 있는가
- 제목/저자/연도 식별이 가능한가
- 논문 외 자료(보고서/법령/회의록)가 섞여 있는가

### 2. 중복 제거
- 제목 동일 또는 유사 제목 통합
- 영문/국문 혼용 중복 통합
- preprint / 출판본 중복 통합
- 같은 기관문서의 요약본/보도자료 중복 구분

### 3. 등급화 원칙
- S/A: 바로 읽어야 하는 핵심 문헌
- B: 보강용, 비교용, 배경용이지만 가치 있음
- C: 주변부 배경문헌
- D: 현재 연구질문과의 관련성이 낮거나 검증 전용

### 4. FULLTEXT_NEEDED 판단
아래 중 하나면 표시합니다.
- 이론을 실제 분석틀로 써야 함
- 코딩 기준/판정 기준이 본문에 있을 가능성이 큼
- 사례 적용 부분이 본문 중심임
- 후속 논문 본문에서 직접 인용할 가능성이 큼

### 5. 채팅 보고 최소형
```text
완료:
- 검색 로그:
- 후보표:
- 초록정리:
- PDF 현황:
- A/S 후보 수:
- FULLTEXT_NEEDED 수:
- 교수님 승인 필요:
```

## 권장 운영 순서

1. 외부 Deep Research로 1차 넓은 탐색
2. Hermes로 후보표/문헌지도 변환
3. A급 핵심문헌만 원문 확보 시도
4. 읽기대기열 갱신
5. 프로젝트별 개요/분석틀로 연결

---

## 실패 방지 규칙

- 외부 Deep Research 결과를 그대로 최종 진실처럼 취급하지 않는다.
- 출처가 부정확하거나 링크가 죽어 있으면 [검증 필요]로 남긴다.
- 후보가 많더라도 1차는 넓게 받고, Hermes 단계에서 줄인다.
- 외부 DR의 미려한 문장보다 **재사용 가능한 표와 파일**을 우선한다.
