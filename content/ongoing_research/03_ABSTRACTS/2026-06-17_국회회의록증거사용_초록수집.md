- 연도: 2019
- 학술지: 교육행정학연구
- DOI/URL: 10.22553/keas.2019.37.2.223 / https://www.dbpia.co.kr/journal/articleDetail?nodeId=NODE10617238
- API 출처: paper_detail + search_dbpia
- 초록 원문: 이 연구는 고등교육법 개정 과정에서 활용된 증거의 유형과 특징, 관련 쟁점을 분석하였다. 국회 회의록과 정부 보도자료를 검토한 결과, 이해관계자의 경험 및 협의, 이전 법령 및 정책의 해석, 기술적 통계 증거가 많이 활용되었고, 핵심 단계에서는 이해관계자의 지식 또는 경험 증거 의존이 두드러졌다. 결과적으로 과학적 분석보다 이해관계나 신념체계에 따라 증거가 선택·활용되는 경향을 확인하였다.
- Hermes 3문장 요약: 교수님 주제와 가장 직접적으로 맞닿은 국내 선행연구입니다. 국회 회의록에서 증거가 어떻게 선택되는지 자체를 다뤘다는 점이 핵심입니다. 상징적·전술적 사용 가설의 국내 입법사례 기준문헌으로 적합합니다.

## 2. 교육정책의 증거 기반 결정 양상 분석
- 저자: 정광호, 진상언, 김수정, 서은솔, 정동욱
- 연도: 2026
- 학술지: 교육행정학연구
- DOI/URL: 10.22553/keas.2026.44.1.827
- API 출처: paper_detail
- 초록 원문: 2022~2025년 교육부 정책 결정 문서를 활용하여 증거의 유형과 위계 수준, 활용 결정 요인을 분석하였다. 학술 연구를 토대로 한 과학적 증거 활용은 매우 제한적이었고, 높은 수준의 인과증거 활용 역시 낮았다. 증거는 정책 대안의 효과 검증보다 정책 문제의 심각성과 정책 추진 필요성을 정당화하는 방식으로 자주 활용되었다.
- Hermes 3문장 요약: 회의록은 아니지만 국내 정책문서에서 증거가 정당화 도구로 쓰인다는 점을 실증적으로 보여줍니다. 교수님 주제의 핵심 명제와 결이 같습니다. 입법부 사례와 병치하면 상징적 사용 논리를 강화할 수 있습니다.
- 관련 개념 후보: [[증거기반정책]], [[정책정당화]], [[증거위계]]
- 등급 초안: A

## 3. 국회의원은 난민을 어떻게 인식하는가?
- 저자: 심은지, 정헌주
- 연도: 2023
- 학술지: 국가정책연구
- DOI/URL: 10.17327/ippa.2023.37.1.002
- API 출처: paper_detail
- 초록 원문: 제18대 국회부터 제21대 국회 전반기까지 난민을 언급한 회의록을 대상으로 내용분석을 실시하여 국회의원의 인식을 확인하였다. 유의미한 발언을 식별한 후 긍정적 의미와 부정적 의미의 언급 단위로 구분하고, 시간 흐름과 사회적 이슈에 따라 인식 변화를 분석하였다.
- Hermes 3문장 요약: 회의록 발언을 의미 단위로 자르는 구체적 선례입니다. 교수님 주제에서도 "증거 발화"를 유의미 단위로 추출하는 데 참고할 수 있습니다. 시기별 변화 분석 구조도 유용합니다.
- 관련 개념 후보: [[내용분석]], [[국회회의록]], [[시계열분석]]
- 등급 초안: A

## 4. 국회 내 원조규범 인식에 대한 내용분석
- 저자: 변지영, 남수정
- 연도: 2017
- 학술지: 지역과 세계
- DOI/URL: 10.33071/ssricb.41.2.201708.313
- API 출처: paper_detail
- 초록 원문: 제16대-제19대 국회 원조 관련 주요 상임위원회 회의록 내용분석을 통해 국회의원들이 원조규범을 어떻게 수용하였는지 시계열적으로 검토하였다. 2010년 국제개발협력기본법 마련을 기점으로 원조 관련 발언 횟수는 감소했지만, 발언 양상은 양적 확대에서 질적 향상 도모로 변화했다. 상임위 이해관계를 반영하려는 경향도 확인되었다.
- Hermes 3문장 요약: 상임위 회의록을 시계열로 읽어 규범 수용 변화를 본 연구입니다. 위원회별 이해관계가 발언 양상을 바꾼다는 점이 중요합니다. 교수님 주제에서 상임위별 차이를 볼 때 직접적인 참조점입니다.
- 관련 개념 후보: [[상임위원회]], [[정책변화]], [[내용분석]]
- 등급 초안: A

- 연도: 2010
- 학술지: 담론201
- DOI/URL: 10.17789/discou.2010.13.4.003
- API 출처: paper_detail
- 초록 원문: 2000~2006년 국회회의록 내용분석을 통해 일-가족 양립 문제가 입법과정에서 어떤 프레임으로 제시되었는지 검토하였다. 핵심 프레임은 국가경쟁력 강화와 저출산·고령화 위기라는 두 패키지로 분류되었다. 정책 대상은 주로 여성으로 한정되었다.
- Hermes 3문장 요약: 프레임 패키지를 도출하는 방식이 교수님 주제의 프레이밍 분석 파트와 가장 가깝습니다. 증거 발화가 어떤 상위 프레임과 결합되는지 코딩할 때 바로 참고할 수 있습니다. 프레임 변화 추적 논리도 유용합니다.
- 관련 개념 후보: [[프레이밍]], [[정책담론]], [[국회회의록]]

- API 출처: paper_detail
- 초록 원문: 자동화된 텍스트분석 기법인 토픽모델링을 활용하여 20대 국회 보건복지위원회 회의록을 분석하였다. 발언 빈도가 높은 16개 토픽을 추출하고 정당별, 주제별, 시기별, 의원 특성별 대결 구도를 확인하였다.

- 저자: 윤성원
- 연도: 2022
- 학술지: 공공정책연구
- DOI/URL: 10.33471/ila.39.2.2
- API 출처: paper_detail
- 초록 원문: 증거기반정책의 개념과 연구 동향을 정리하고 복지정책 분야 적용 사례를 분석하였다. 한국은 행정 빅데이터 활용과 정책실험이 아직 제약이 많아 증거 기반 정책결정 문화가 충분히 정착되지 못했다고 보았다.

## 10. 증거기반정책의 발전과 성숙
- 저자: 주상원, 이재호, 김병조
- 연도: 2022
- 학술지: 한국사회와 행정연구
- DOI/URL: 10.53865/kspa.2022.11.33.3.97
- API 출처: paper_detail
- 초록 원문: 미얀마, 인도네시아, 일본, 홍콩, 한국 등 아시아 5개국의 증거기반정책 도입 및 운영 현황을 검토하였다. 집행 성숙도는 탐색, 도입, 집행, 지속의 4단계 가운데 지속단계를 제외하고 분포하여 충분히 성숙하지 못한 것으로 평가되었다.
- Hermes 3문장 요약: 한국을 포함한 비교 맥락에서 EBP 제도 성숙도가 높지 않음을 보여줍니다. 입법부의 증거 사용을 넓은 정책체계의 미성숙과 연결할 수 있습니다. 직접 회의록 분석은 아니므로 배경문헌으로 적절합니다.
- 관련 개념 후보: [[비교정책]], [[증거기반정책]]
- 등급 초안: B
