# 논문 프로젝트 현황판

이 문서는 진행중 논문의 중앙 지휘판이다. Hermes, Codex, 사용자는 작업이 끝날 때마다 이 표의 `현재 단계`, `다음 행동`, `최근 산출물`을 갱신한다.

## 단계 정의

| 단계 | 의미 | 다음 단계 |
|---|---|---|
| 0_아이디어 | 주제만 있음 | 작업지시 작성 |
| 1_수집대기 | Hermes 작업지시 작성 완료 | API 검색·초록 수집 |
| 2_문헌수집 | 후보표·초록·PDF 확보 진행 | 후보 등급화 |
| 3_선별 | A/B/C/D 등급화 | PDF 원문 읽기 |
| 4_원문읽기 | 핵심 문헌 원문 확인 | 논문노트·문헌지도 |
| 5_설계 | 연구질문·분석틀·목차 작성 | 초록·서론 |

| 7_수정 | 논지·문헌·문장 수정 | 투고본 |
| 8_완료 | 투고 가능본 또는 보류 결정 | 위키 반영 |

## 오늘의 지휘 메모

- 1순위 프로젝트는 Hermes 1차 수집 완료. 이제 A/B/C/D 확정과 정책영역 선택 단계로 전환한다.
- 2순위 프로젝트는 Hermes 1차 수집 완료. 이제 A/B/C 등급 확정과 법령·정부문서·국회자료 표본축 선택 단계로 전환한다.
- 초록 수집 결과만으로 본문을 작성하지 않는다.
- 초고 착수 전 `08_GATES/승인체크리스트.md`에서 사용자가 승인한다.
- 각 프로젝트는 `06_DRAFTS/{프로젝트명}/`에 초고 폴더를 둔다.

## 사용 규칙
- 새 research job 또는 장기 논문 프로젝트를 시작할 때 이 문서에 항목을 추가합니다.
- 사용자가 `연구잡 상태`, `진행 중인 논문들`, `지난번 주제 이어서`라고 말하면 이 문서를 우선 확인합니다.
- `현재 단계`, `다음 행동`, `최근 산출물/핵심 산출물`은 작업이 끝날 때마다 갱신합니다.
