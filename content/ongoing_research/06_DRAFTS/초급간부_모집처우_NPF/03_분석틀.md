# 03_분석틀 — 초급간부 모집·처우 NPF

## 핵심 개념
- **서사적 행위자**: hero / villain / victim / beneficiary / burden
- **플롯**: 안보위기, 인구절벽, 공정성 훼손, 직업성 약화, 보상 회복
- **도덕적 교훈**: 더 많은 보상, 제도개혁, 복무환경 개선, 선발체계 개편, 조직문화 개선

## 1차 코딩축(안)
1. 초급간부는 어떻게 호명되는가?
   - 국가안보의 중추 / 희생당한 집단 / 특혜집단 / 기피직종 / 전문직업군
2. 문제 원인은 어디에 놓이는가?
   - 인구감소 / 처우 / 직업안정성 / 조직문화 / 공정성 인식 / 사회적 이미지
3. 해결책은 어떻게 정당화되는가?
   - 급여·복지 인상 / 장기복무 보장 / 선발제도 조정 / 홍보 강화 / 교육훈련 개선

## 가설 초안
- **H1**: 정부·군 공식담론은 초급간부를 hero로 호명하면서도, 실제 정책도덕은 개인 희생의 지속을 요구하는 방향으로 서사화할 가능성이 높다.
- **H2**: 비판적 담론은 초급간부를 victim으로 서사화하며 처우·형평성 문제를 전면화할 가능성이 높다.
- **H3**: 모집위기 대응정책은 안보위기 플롯과 공정성 플롯이 경쟁하는 가운데 정당화될 가능성이 높다.

## 대안 설명
- 단순히 급여 수준만의 문제가 아닐 수 있음
- 직업 전망의 불확실성과 사회적 위신 저하가 더 큰 설명력을 가질 수 있음
- 출신별 형평성과 장기복무 선발체계가 병목일 가능성

## 확정된 설계 조건
- 분석 대상: **초급간부(장교+부사관)**
- 코퍼스 축 1: **국회회의록**
- 코퍼스 축 2: **국방부/병무청 보도자료**
- 목적: 두 코퍼스가 초급간부를 어떻게 다르게 서사화하는지 비교
