# 06_수집설계 — 초급간부 모집·처우 NPF

`10_다음작업.md`의 "즉시 다음 작업" 3개 항목(수집기간안·키워드세트·촉발기제 연표)을 설계 문서로 구체화한다. **이 파일의 촉발기제 연표는 AI가 일반 지식으로 초안화한 것으로, 이 세션은 웹 검색·국회회의록 시스템·국방부 보도자료 아카이브에 실시간 접근하지 않았다. 실제 수집 착수 전 사용자 또는 Hermes가 원 자료로 반드시 검증해야 한다.**

## 1. 국회회의록 수집기간 3안

| 안 | 기간 | 근거 | 장단점 |
|---|---|---|---|
| A안(최소) | 최근 4년(제22대 국회 임기, 2024~2028 진행분) | 현재 정치 지형·현직 정책주도자와 직접 연결되는 발언만 포착 | 표본 수 적을 위험. 장기 국면 비교 불가 |
| B안(표준, 권장) | 최근 8년(제21~22대 국회, 2020~현재) | 코로나19 이후 병역자원 감소 이슈 부각 시점부터 포착 가능. 국면 3~4개 확보 가능 | 수작업 코딩 부담 증가 — 표본 추출(sampling) 병행 필요 |
| C안(장기) | 최근 12년(제20~22대 국회, 2016~현재) | 병역자원 감소가 통계적으로 가시화되기 시작한 시점부터 포착 | 코딩 범위 과다. 학술지 분량 제약상 비현실적 |

**권고**: B안(2020~현재)을 기본으로 하되, 국정감사 회의록(매년 정례)과 국방위원회 법안심사소위 회의록을 우선 표본으로 삼아 전수조사 대신 목적표집(purposive sampling)한다.

## 2. 국방부/병무청 보도자료 검색 키워드 세트

### 1차 키워드 (직접 검색어)
`초급간부`, `초임장교`, `부사관 지원율`, `장교 지원율`, `장기복무 선발`, `단기복무장려금`, `초급간부 처우개선`, `병역자원 감소`

### 2차 키워드 (제도·정책 명칭 — 확인 필요)
- 장교·부사관 복무제도 개편 관련 정책 명칭은 시점에 따라 바뀌므로, 검색 시점에 국방부·병무청 홈페이지 보도자료실에서 최신 정책 명칭을 먼저 확인한 뒤 키워드를 갱신한다.
- 예시로 참고할 수 있는 상위 카테고리: 군 인력획득 정책, 복무여건 개선 대책, 국방인력계획

### 제외 키워드
`부사관 임관식`(단순 행사보도), `장교 임관식`(단순 행사보도) — 서사 분석 가치가 낮은 의례적 보도는 제외하되, 임관식 축사에 정책 메시지가 포함된 경우는 예외적으로 포함

## 3. 정치적 촉발기제 후보 연표 [AI 초안 — 검증 필수]

아래는 NPFK의 "정치적 촉발기제" 변수 코딩을 위한 후보 국면 유형이다. **구체적 연도·사건명은 이 세션에서 실시간 확인이 불가능하므로, 실제 코딩 착수 전 반드시 국방부·병무청 보도자료 아카이브 및 국회회의록 시스템에서 정확한 날짜·사건을 재확인해야 한다.**

| 촉발기제 유형 | 확인 방법 | 비고 |
|---|---|---|
| 국정감사 국면(매년 정례) | 매년 9~10월 국방위원회 국정감사 회의록 | 병역자원·모집률 통계가 매년 정례적으로 쟁점화되는 제도적 계기 |
| 예산안 심사 국면(매년 정례) | 매년 11~12월 국방위·예산결산특별위 회의록 | 처우개선 예산(수당·급여 인상) 반영 여부가 쟁점화되는 계기 |
| 국방부·병무청 장차관급 인사 교체 | 관보·보도자료로 재직 기간 확인 | 정책주도자 교체가 서사 전환점이 될 수 있음. 코딩 착수 시점의 현직자를 먼저 확인 |
| 병역자원 감소 관련 통계 발표(병무청 연례 통계, 저출산고령사회위원회 발표 등) | 병무청·통계청 공식 발표 자료 확인 | 인구감소 프레임이 강화되는 계기 |
| 안보 관련 돌발사건(도발·사고 등) | 사건 발생 시점을 1차로 언론·국방부 보도자료에서 확인 후 회의록 대조 | **특정 사건을 이 세션에서 단정하지 않음 — 반드시 원 자료로 확인 후 채움** |
| 총선 국면 | 제22대 국회 임기는 2024~2028이므로 이번 수집기간(B안) 내 총선 국면은 원칙적으로 없음. 대통령 선거·보궐선거 등 예외 발생 여부는 확인 필요 | |
