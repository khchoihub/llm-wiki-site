# 09_수석참모종합 — 초급간부 모집·처우 NPF (원문독해 반영본)

## 한 문장 결론
초급간부 모집·처우 문제는 일반 NPF보다 **한국형 수정 NPFK**로 분석하는 편이 더 정확하며, 핵심 변수는 **지지연합·정책서사·정치적 촉발기제·정책주도자**입니다.

## 이번 턴에서 실제로 한 일
- 이재무(2014) 원문 독해
- 이재무(2017) 원문 독해
- 독해 결과를 연구파일에 반영
- 초급간부 주제용 NPFK 코딩축 초안 도출

## 원문독해로 확정된 점
1. 한국 정책담론 분석에는 **NPFK**를 쓰는 것이 타당함
2. 대립 지지연합은 서로 **같은 속성의 전략**도 사용할 수 있음
3. **정치적 촉발기제**와 **정책주도자**는 한국 맥락에서 필수 변수임
4. 여론은 중요하지만 **절대적이지 않음**
5. 최종 정책은 담론경쟁과 정치적 타협의 산물로 읽어야 함

## 교수님 주제에 대한 적용 판단
- 분석 대상: **초급간부(장교+부사관)**
- 데이터축: **국회회의록 + 국방부/병무청 보도자료**
- 핵심 분석변수: 지지연합 / 정책신념 / 정체성전략 / 비용-편익구조전략 / 압축적 상징 / 정책대리 / 촉발기제 / 정책주도자

## 수정된 추천 연구질문
한국의 초급간부 모집·처우 담론에서 초급간부는 어떤 정책서사적 존재로 구성되며, 정치적 촉발기제와 정책주도자는 어떤 방식으로 서사의 방향과 정책대안을 변화시키는가?

## 현재 강점
1. 방법론 핵심문헌을 실제 원문 기준으로 소화함
2. 공개 텍스트 자료만으로도 코딩 설계가 가능함
3. 군 인사·사관학교·청년거버넌스 맥락을 함께 연결할 수 있음

## 남은 핵심 병목
1. 회의록 수집 기간 확정
2. 보도자료 수집 키워드 확정
3. 시기 구분(국면화) 초안 작성
4. 코딩표 실제 작성

## 현재 단계 판단
- 주제 적합성: 매우 높음
- 이론 적합성: 매우 높음
- 자료 접근성: 높음
- 논문화 속도: 높음
- 다음 단계: **method_design**
