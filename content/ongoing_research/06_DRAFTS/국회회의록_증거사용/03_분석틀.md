# 분석틀

## 분석 단위

- 1차 후보: 증거가 인용된 발언문
- 2차 후보: 증거 인용 문장

## 증거 유형 코드

| 코드 | 정의 | 예시 |
|---|---|---|
| 통계 | 수치, 지표, 조사 결과 | 출산율, 예산액, 수혜자 수 |
| 학술연구 | 논문, 연구보고서, 학자 연구 | 국내외 논문, 연구기관 보고서 |
| 전문가 진술 | 전문가 의견 또는 공청회 진술 | 교수, 연구자, 협회 전문가 |
| 해외사례 | 외국 제도·정책 사례 | OECD, 일본, 독일 사례 |
| 행정자료 | 정부 부처 자료 | 부처 통계, 사업평가 |
| 현장사례 | 민원, 사례, 현장 목소리 | 피해 사례, 지역 사례 |

## 증거 사용 유형 코드

| 코드 | 정의 |
|---|---|
| 도구적 사용 | 정책 대안 선택이나 수정에 직접 사용 |
| 개념적 사용 | 문제 이해나 관점 형성에 사용 |
| 상징적 사용 | 이미 정한 입장을 정당화하는 데 사용 |
| 전술적 사용 | 논쟁 지연, 반대 약화, 책임 회피에 사용 |

## 프레임 코드

| 코드 | 정의 |
|---|---|
| 문제정의 | 무엇이 문제인지 규정 |
| 책임귀속 | 누가 원인 또는 책임자인지 규정 |
| 정책정당화 | 특정 정책의 필요성 강조 |
| 비용방어 | 재정·행정부담·부작용 방어 |
| 반대근거 약화 | 반대 논리를 비판하거나 무력화 |
