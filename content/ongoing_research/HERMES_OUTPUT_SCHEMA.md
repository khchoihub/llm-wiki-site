# Hermes 산출물 고정 양식

Hermes는 검색 결과를 자유 요약으로 끝내지 않는다. 모든 연구 주제는 아래 네 종류의 산출물을 남긴다.

## 1. 검색 로그

저장 위치:

```text
ongoing_research/01_SEARCH_LOG/{YYYY-MM-DD}_{주제}_검색로그.md
```

필수 항목:

| 항목 | 내용 |
|---|---|
| 실행일시 |  |
| 실행자 | Hermes |
| 주제 |  |
| 사용 DB/API | ScienceON, KCI 등 |
| 검색어 |  |
| 검색 조건 | 연도, 분야, 정렬, 건수 |
| 결과 수 |  |
| 실패·오류 | rate limit, 인증 실패, 원문 접근 실패 등 |
| 다음 검색어 |  |

## 2. 후보 논문표

저장 위치:

```text
ongoing_research/02_CANDIDATES/{YYYY-MM-DD}_{주제}_후보표.md
```

필수 열:

| 등급 | 연도 | 저자 | 제목 | 학술지 | 연구유형 | 초록 핵심 | 관련성 판단 | DOI/URL | PDF | 원문 경로 | 다음 행동 |
|---|---:|---|---|---|---|---|---|---|---|---|---|

등급:

- A: 즉시 원문 읽기 및 논문노트화
- B: 읽기대기열 등록
- C: 배경문헌
- D: 제외

## 3. 초록 수집

저장 위치:

```text
ongoing_research/03_ABSTRACTS/{YYYY-MM-DD}_{주제}_초록수집.md
```

각 논문마다 필수 항목:

- 제목
- 저자
- 연도
- 학술지
- DOI/URL
- API 출처
- 초록 원문
- Hermes 3문장 요약
- 관련 개념 후보
- 등급 초안

## 4. PDF 확보 현황

저장 위치:

```text
ongoing_research/04_PDFS/{YYYY-MM-DD}_{주제}_PDF확보현황.md
```

필수 열:

| 상태 | 파일명 후보 | 실제 저장 경로 | 제목 | 출처 | 원문 접근 방식 | 비고 |
|---|---|---|---|---|---|---|

상태:

- 확보
- 대기
- 접근불가
- 원문불필요

PDF 원본은 Git에 넣지 않는다. 원본은 `G:\내 드라이브\llm-wiki-papers\`에 저장하고, 이 표에는 경로만 기록한다.
